# 🌏 South Asia Dashboard

An interactive **Streamlit dashboard** for exploring and analyzing South Asian data through visualizations and insights. The dashboard enables users to understand trends, compare countries, and interact with the dataset using dynamic charts and filters.

## 🚀 Live Demo

🔗 https://south-asia-dashboard-ekvi6vcywcgpaykmpkwkr5.streamlit.app/

---

## 📌 Features

- 📊 Interactive data visualizations
- 🌍 Country-wise analysis
- 📈 Trend analysis with charts
- 🔍 Dynamic filtering and exploration
- ⚡ Fast and responsive Streamlit interface
- 📱 User-friendly dashboard

---

```

## 📦 Installation

### Clone the Repository

```bash
git clone https://github.com/Sameerchakare56/South-Asia-Dashboard.git
```

### Navigate to Project Folder

```bash
cd South-Asia-Dashboard
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```

## 📊 Dataset

The project uses a cleaned South Asia dataset stored in:

```

```

The dataset is used for generating interactive visualizations and analysis.
